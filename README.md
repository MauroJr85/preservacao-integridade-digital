# 🔐 Preservação e Integridade Digital

**Integridade de arquivos | Automação com PowerShell | Preservação digital**

## 📌 Sobre o projeto

O **Preservação e Integridade Digital** é uma ferramenta desenvolvida em PowerShell para apoiar procedimentos de cópia, preservação e verificação de integridade de arquivos digitais.

O projeto surgiu da necessidade de tornar determinadas operações de preservação mais organizadas, padronizadas e verificáveis, utilizando mecanismos de comparação criptográfica e registros documentais.

A aplicação possui interface gráfica e foi concebida para execução local em ambiente Windows.

## 🎯 Objetivo

Desenvolver uma solução de apoio à preservação de arquivos digitais, automatizando operações repetitivas e permitindo verificar se o conteúdo dos arquivos preservados permanece consistente com os registros produzidos.

A proposta combina automação, integridade digital, organização documental e rastreabilidade.

## ⚙️ Principais funcionalidades

- Seleção e organização de arquivos para preservação;
- Criação de cópias em estruturas de armazenamento organizadas;
- Cálculo de hashes criptográficos SHA-256;
- Comparação de integridade entre arquivos de origem e respectivas cópias;
- Registro de informações sobre as operações executadas;
- Geração de manifestos e relatórios;
- Verificação posterior da integridade dos arquivos preservados;
- Identificação de divergências, arquivos ausentes e inconsistências;
- Interface gráfica para facilitar a interação com o usuário;
- Funcionamento local, sem dependência de serviços externos.

O projeto busca reduzir intervenções manuais e facilitar a identificação de problemas durante as operações de preservação e verificação.

## 🛠️ Tecnologias e conceitos aplicados

- PowerShell;
- Windows Forms;
- Criptografia aplicada à integridade digital (SHA-256);
- Manipulação de arquivos;
- Automação de processos;
- Geração de relatórios;
- Tratamento de erros e validação de informações.

## 🧩 Desenvolvimento e decisões técnicas

O desenvolvimento foi orientado pela necessidade de conciliar simplicidade operacional, confiabilidade e facilidade de utilização.

Entre as preocupações consideradas estão:

- Preservação do conteúdo original durante as operações;
- Verificação das cópias produzidas;
- Registro dos resultados e eventuais inconsistências;
- Organização das informações para conferência posterior;
- Tratamento de situações de erro ou interrupção;
- Usabilidade por meio de interface gráfica.

## ⚠️ Escopo e limitações

A ferramenta constitui um recurso auxiliar para preservação e verificação de integridade de arquivos digitais.

**Não realiza aquisição forense integral de dispositivos e não substitui procedimentos formais de cadeia de custódia, políticas institucionais ou ferramentas forenses especializadas.**

A utilização de hashes permite verificar a consistência do conteúdo comparado, mas não comprova, isoladamente, autoria, origem legítima ou autenticidade de uma evidência.
